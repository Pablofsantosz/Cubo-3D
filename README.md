# Proposta do Projeto
Nossa proposta inicial foi a construção de um cubo mágico utilizando a biblioteca de Three.JS de JavaScript em junção com uma página HTML para renderização 3D do objeto.

# Realização 
O projeto aqui entregue se trata de um cubo mágico em 3D renderizado utilizando bibliotecas de JavaScript em uma página HTML, o cubo é constituido por faces 3x3x3 cada uma com sua cor específica. É possível rotacionar o cubo com controles do mouse, girar suas peças a fim de embaralhar e resolvê-lo. A rotação das faces é feita de forma suave e e as rotações podem ser feitas em todas as faces do cubo.

# Como Executar
Para executar o programa basta abrir o arquivo HTML num navegador de sua preferência.
